# AI 업무 과제 연습실 작업 공간

여기는 연습실 과제를 푸는 작업 공간입니다. 창이 둘 필요합니다. 지금 보는 이 창(작업 공간)에서 코딩 AI와 코드를 다루고, 연습실 창(careerxp.work/ax/practice/room)에서는 남은 시간을 보고 담당자에게 물어보고 제출합니다.

아래 1번부터 4번까지 한 번만 하면 됩니다. 이미 로그인한 도구는 건너뛰세요.

처음 열면 「이 폴더에 있는 파일의 작성자를 신뢰합니까?」(영어 화면은 Do you trust the authors) 창이 뜹니다. 「폴더 신뢰 및 계속」을 누르세요. 이 작업 공간에는 연습실 도구만 들어 있고, 신뢰해야 터미널이 열립니다.

## 1. 접속 코드로 연결

연습실 창의 작업 패널에 `prac_` 로 시작하는 접속 코드가 있습니다. 아래 터미널(없으면 메뉴의 Terminal > New Terminal)에 붙여넣으세요.

```
practice login prac_xxxxxxxx
```

코드는 이 과제 하나에만 쓰입니다. 연습실 창에서 새 코드를 받으면 앞의 코드는 못 씁니다.

## 2. Codex 로그인

ChatGPT 설정의 보안에서 기기 코드 로그인을 먼저 켭니다. 그다음 터미널에서

```
codex login --device-auth
```

화면에 나온 주소를 브라우저로 열고, 같이 나온 코드를 입력하면 됩니다.

## 3. Claude Code 로그인

터미널에서 `claude` 를 실행하면 주소가 나옵니다. 그 주소를 열어 로그인하고, 브라우저에 나온 코드를 터미널에 붙여넣으세요. 이 방법이 안 되면 내 컴퓨터 터미널에서 `claude setup-token` 으로 토큰을 받아, 이 작업 공간의 터미널에서 아래처럼 넣습니다.

```
export CLAUDE_CODE_OAUTH_TOKEN=받은_토큰
```

## 4. 과제 받기

```
practice start
```

이 명령을 실행하는 순간 시간이 흐르기 시작합니다. 과제 파일은 `assignment/` 폴더에 풀립니다. `assignment/README.md` 부터 읽으세요. 사용량을 연습실 창에 알려 주는 프로그램이 뒤에서 같이 켜집니다.

## 5. 창 나누기

화면 한쪽에는 이 작업 공간, 다른 쪽에는 연습실 창을 두면 편합니다. Windows에서는 창을 고른 뒤 Win + 왼쪽 화살표, 다른 창에서 Win + 오른쪽 화살표를 누르면 반씩 나뉩니다. Mac은 초록색 단추를 길게 누르세요.

## 제출

과제를 마치면 연습실 창의 「제출하고 문제풀기」를 누르세요. 작업 공간이 알아서 결과물을 모아 올립니다. 직접 올리려면 터미널에서 `practice submit` 입니다.

## 비용에 대해

- 이 작업 공간은 내 GitHub 계정의 Codespaces 사용량으로 돌아갑니다.
- Codex와 Claude Code는 내 구독 계정으로 로그인합니다. API 키가 있으면 Codespaces 비밀값 `OPENAI_API_KEY`, `ANTHROPIC_API_KEY` 로 둘 수도 있습니다.
- 연습실이 내 AI 비용을 대신 내거나 청구하지 않습니다. 연습실 창에 보이는 AI 사용량은 토큰 수를 API 가격표로 셈한 참고 값입니다.

## 막혔을 때

- `practice status` 로 남은 시간과 연결 상태를 볼 수 있습니다.
- 「서버에 연결하지 못했습니다」가 나오면 인터넷 연결을 확인하고 잠시 뒤 다시 해 보세요. 명령은 알아서 몇 번 다시 시도합니다.
- 그래도 안 되면 연습실 창의 「문제 신고」에 상황을 적어 주세요.
