# AI 업무 과제 연습실 작업 공간

여기는 연습실 과제를 푸는 작업 공간입니다. 창이 둘 필요합니다. 지금 보는 이 창(작업 공간)에서 Codex와 코드를 다루고, 연습실 창(careerxp.work/ax/practice/room)에서는 남은 시간을 보고, 오른쪽 대화로 업무 담당자에게 물어보고, 제출합니다.

아래 1번부터 3번까지 한 번만 하면 됩니다. 이미 로그인했다면 2번은 건너뛰세요. 실제 2차 예선은 제공된 Codex만 쓸 수 있어서, 이 작업 공간도 Codex만 둡니다. Claude Code나 다른 AI 도구는 쓰지 마세요. 써도 막히지는 않지만 연습실 창과 리포트에 실제로는 쓸 수 없는 도구를 썼다고 표시됩니다.

처음 열면 "이 폴더에 있는 파일의 작성자를 신뢰합니까?"(영어 화면은 Do you trust the authors) 창이 뜹니다. "폴더 신뢰 및 계속"을 누르세요. 이 작업 공간에는 연습실 도구만 들어 있고, 신뢰해야 터미널이 열립니다.

## 1. 접속 코드로 연결

연습실 창의 작업 패널에 `prac_` 로 시작하는 접속 코드가 있습니다. 아래 터미널에 붙여넣으세요. 터미널이 안 보이면 메뉴에서 터미널, 새 터미널을 차례로 고릅니다(영어 화면은 Terminal, New Terminal).

```
practice login prac_xxxxxxxx
```

코드는 이 과제 하나에만 쓰입니다. 연습실 창에서 새 코드를 받으면 앞의 코드는 못 쓰고, 이미 연결돼 있던 터미널도 끊깁니다. 새 코드를 받았다면 같은 명령을 새 코드로 다시 실행하세요.

## 2. Codex 로그인

ChatGPT 설정의 보안에서 "기기 코드 로그인"을 먼저 켭니다. 켜 두지 않으면 로그인이 브라우저 방식으로 넘어가 작업 공간에서는 끝내기 어렵습니다. 그다음 터미널에서

```
codex login --device-auth
```

화면에 나온 주소를 브라우저로 열고, 같이 나온 코드를 입력하면 됩니다.

작업 공간 화면 한쪽에 "GitHub 로그인"이나 "AI 기능"을 켜라는 Copilot 안내가 뜰 수 있습니다. VS Code 에 들어 있는 다른 AI 라 이 연습실과 2차에서는 쓰지 않습니다. 닫고 넘어가면 되고, AI 는 터미널의 codex 만 씁니다.

## 3. 과제 받기

1번에서 로그인하면 뒤에서 지켜보는 프로그램(practice watch)이 켜지고, 연습실 창에 "과제 시작" 단추가 열립니다. 준비가 됐으면 그 단추를 누르세요. 이 작업 공간이 과제 파일을 받고 시간이 흐르기 시작합니다. 터미널에서 아래 명령을 실행해도 같습니다.

```
practice start
```

과제 시작을 누르거나 이 명령을 실행하는 순간 시간이 흐르기 시작합니다. 실전 과제는 시작하는 순간부터 환불되지 않습니다. 사전 체험은 시작으로 보지 않습니다.

과제 파일은 `assignment/` 폴더에 풀립니다. 작업은 모두 그 폴더 안에서 합니다. 터미널이 그 폴더가 아니면 `cd assignment` 를 한 번 실행하고, 그 폴더에서 `codex` 를 실행하세요. Codex의 승인 방식은 바꾸지 말고 기본값 그대로 두세요. 실제 2차도 필요할 때 승인을 묻는 기본 설정입니다. codex 가 명령을 실행하거나 파일을 바꾸기 전에 "1. Yes, proceed" 처럼 영어로 물으면 방향키로 고르고 Enter 를 누릅니다. 1 은 이번 한 번만 허락, 2 는 같은 말로 시작하는 명령은 다음부터 묻지 않고 허락, 3 은 거절입니다. codex 안에서 `/status` 를 입력하면 지금 쓰는 모델과 권한이 보이고, `/model` 로 모델을 고를 수 있습니다. 실제 2차는 Astra 사용이 제한되고 Sol 6.1, Terra 5.6, Luna 6, Sol 6.0 을 권하니 연습도 그 안에서 고르세요. 내 계정 목록에 없으면 비슷한 모델이면 됩니다. `npm` 명령도, 결과물을 만드는 위치도 그 폴더가 기준입니다. `assignment/README.md` 부터 읽으세요. 지켜보는 프로그램(practice watch)은 과제를 시작한 뒤에도 계속 돌며 사용량을 연습실 창에 알립니다. 과제 시작을 눌렀는데 시작되지 않으면 practice status 를 한 번 실행하거나, practice start 를 직접 실행하세요.

## 4. 창 나누기

화면 한쪽에는 이 작업 공간, 다른 쪽에는 연습실 창을 두면 편합니다. Windows에서는 창을 고른 뒤 Win + 왼쪽 화살표, 다른 창에서 Win + 오른쪽 화살표를 누르면 반씩 나뉩니다. Mac은 초록색 단추를 길게 누르세요.

## 터미널 쓰는 법

- 복사: 마우스로 끌어 글을 고른 뒤 Ctrl+C 를 누릅니다(Mac은 Command+C).
- 붙여넣기: Ctrl+Shift+V 입니다(Mac은 Command+V). Windows 에서는 Ctrl+V 도 됩니다.
- NOTES.md 같은 파일 창에서는 Ctrl+C 와 Ctrl+V 를 씁니다. 파일 창에서 Ctrl+Shift+V 를 누르면 붙여넣기 대신 그 창이 미리보기로 바뀝니다. 한 번 더 누르면 돌아옵니다.
- 터미널에서 한글이 자음과 모음으로 나뉘어 들어가면, 한글 문장은 파일 창에 먼저 써서 복사한 뒤 터미널에 붙여넣으세요.
- 글을 고르지 않고 누른 Ctrl+C 는 복사가 아니라 돌던 명령이나 codex 를 멈춥니다. 서버를 끌 때만 쓰세요.
- 서버가 도는 터미널 탭은 닫지 마세요. 닫으면 서버도 같이 꺼질 수 있습니다. 다른 명령은 터미널 위쪽의 + 단추로 새 터미널을 열어 실행합니다. 분할 단추를 누르면 터미널 둘을 나란히 둘 수 있습니다.

## 만든 화면을 미리보기로 열기

웹 화면을 만드는 과제라면 서버를 띄운 뒤 VS Code 안 미리보기 창으로 엽니다. 실제 2차의 Browser 도구와 같은 자리입니다.

- 서버는 `0.0.0.0` 에 띄웁니다. `localhost` 에만 띄우면 미리보기 창에 화면이 뜨지 않습니다. 예를 들어 Vite는 `npm run dev -- --host 0.0.0.0`, Python은 `python -m http.server 8000 --bind 0.0.0.0` 입니다.
- 3000, 5173, 8000, 8080 포트는 서버가 뜨면 미리보기 창이 저절로 열립니다. 다른 포트를 썼다면 아래쪽 패널의 포트 탭에서 그 포트 줄의 지구본 옆 미리보기 단추를 누릅니다.
- 첫 화면이 아닌 곳을 보려면 미리보기 주소창 끝에 경로(예: `/admin`)를 붙입니다.

## 제출

과제를 마치면 연습실 창의 "제출하고 문제풀기"를 누르세요. 작업 공간이 알아서 결과물을 모아 올리고, 보통 1분에서 5분쯤 걸립니다. 직접 올리려면 터미널에서 `practice submit` 입니다.

`practice submit` 을 실행해 제출을 요청하면 그 순간부터 업무 담당자와 과제 도우미에게 더 물을 수 없고, 되돌릴 수도 없습니다. 연습 삼아 쳐 보는 명령이 아니라서 터미널이 한 번 묻습니다. `y` 를 입력하면 제출하고, 다른 키를 누르면 멈춥니다. 묻지 않고 바로 내려면 `practice submit --yes` 입니다.

제출 확인 화면에서 빠진 것을 발견하면, 확인 문제를 시작하기 전에는 고친 뒤 `practice submit --again` 으로 다시 올릴 수 있습니다.

## 비용에 대해

- 이 작업 공간은 내 GitHub 계정의 Codespaces 사용량으로 돌아갑니다.
- Codex는 내 ChatGPT 계정으로 로그인합니다. 실제 2차는 개인 API 키와 개인 구독을 쓸 수 없고 제공된 Codex만 씁니다. 연습실은 그 계정을 드릴 수 없어서 내 계정을 빌려 쓰는 것만 다릅니다.
- 연습실이 내 AI 비용을 대신 내거나 청구하지 않습니다. 연습실 창에 보이는 AI 사용량은 토큰 수를 API 가격표로 셈한 참고 값입니다.

## 다음 과제로 넘어갈 때

다음 과제(또는 다시 풀기)는 연습실 창에서 그 과제를 열고 새 접속 코드를 받아 `practice login 새 코드` 를 실행한 뒤 `practice start` 를 실행합니다. 앞 과제의 assignment 폴더는 지우지 않고 다른 이름으로 옮겨 둡니다. 같은 작업 공간을 계속 써도 됩니다.

## 작업 공간이 멈췄다가 다시 켜졌을 때

Codespaces는 30분 동안 아무 입력이 없으면 멈추는 것이 기본값입니다. 멈췄다가 다시 열었다면 터미널에서 `practice status` 를 한 번 실행하세요. 꺼진 지켜보는 프로그램(practice watch)을 다시 켜 주고 남은 시간도 보여 줍니다. 마감 때의 자동 제출과 연습실 창의 연결 표시가 이 프로그램에 달려 있습니다.

멈추는 시간은 내 GitHub 설정의 Codespaces 항목에서 늘릴 수 있습니다. 시간이 흐르는 과제를 시작하기 전에 늘려 두면 편합니다.

작업 공간을 새로 만들었다면(Rebuild Container) 연결 정보가 지워집니다. 연습실 창의 같은 접속 코드로 `practice login` 을 다시 실행하고, 이어서 `practice start` 를 실행하세요. 이미 시작한 응시라면 남은 시간은 처음부터 흐르던 그대로이고, assignment 폴더에 있던 작업도 그대로 이어집니다.

## 막혔을 때

- `practice status` 로 남은 시간과 연결 상태를 볼 수 있습니다.
- "서버에 닿지 못했습니다"가 나오면 인터넷이 켜져 있는지 보고 잠시 뒤 다시 해 보세요. "서버가 바쁩니다"는 서버가 응답은 했지만 지금 처리하지 못한다는 뜻입니다. 두 경우 모두 명령이 알아서 몇 번 다시 시도합니다.
- 접속 코드가 맞지 않거나 만료됐다고 나오면 연습실 창에서 새 코드를 받아 `practice login` 을 다시 실행하세요.
- "작업 공간의 연습실 도구가 예전 판입니다"라고 나오면 터미널에서 `cd /workspaces/samcoach-ai-practice` 로 옮긴 뒤 `git pull` 을 실행하고, 이어서 `npm i -g ./tools/practice` 를 실행하세요. 터미널은 assignment 폴더에서 열려서, 옮기지 않으면 두 명령 모두 실패합니다.
- `practice start` 를 실행했는데 "작업 공간 폴더에서 실행해 주세요"라고 나오면 새 터미널을 열어서 다시 실행하세요. 터미널이 저장소 밖(홈 폴더 등)에서 열려 있을 때 나오는 안내입니다.
- 그래도 안 되면 연습실 창의 "문제 신고"에 상황을 적어 주세요.
